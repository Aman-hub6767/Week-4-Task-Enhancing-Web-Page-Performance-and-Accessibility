# Week 4 Task: Enhancing Web Page Performance and Accessibility

## Project Overview

This project focuses on improving the performance, accessibility, and overall quality of the ShopEase e-commerce website. The website is built using HTML, CSS, and JavaScript. Google PageSpeed Insights was used to evaluate the website's performance and accessibility.

## Objectives

- Improve website loading speed.
- Follow semantic HTML practices.
- Make the website accessible to a wider range of users.
- Optimize CSS and reduce unnecessary code.
- Evaluate performance and accessibility using testing tools.

## Technologies and Tools Used

- **HTML5:** Structures the webpage using HTML elements.
- **CSS3:** Provides styling and responsive layouts.
- **JavaScript:** Adds interactive functionality.
- **Google PageSpeed Insights:** Evaluates website performance, accessibility, best practices, and SEO.

## Performance and Accessibility Results

The website was tested using Google PageSpeed Insights in Desktop mode.

| Category | Score |
|---|---:|
| Performance | 98/100 |
| Accessibility | 92/100 |
| Best Practices | 100/100 |
| SEO | 100/100 |

The results indicate strong desktop performance, with high scores in all four categories. Accessibility received a score of 92, indicating that there may still be opportunities to improve accessibility.

## Improvements and Optimization Areas

### Performance
- Review image sizes and use optimized image formats where appropriate.
- Reduce unnecessary CSS and JavaScript.
- Remove duplicate CSS rules where possible.
- Use efficient resource loading techniques.

![Performance Speed]("Performance Speed.png")

### Accessibility
- Use semantic HTML elements such as `header`, `nav`, `main`, and `footer`.
- Add meaningful alternative text to informative images.
- Ensure buttons and form fields have accessible names.
- Maintain sufficient color contrast.
- Check keyboard navigation and visible focus indicators.

![Web Accessibility]("Web Accessibility.png")

### Code Quality
- Keep HTML, CSS, and JavaScript organized in separate files.
- Use clear and consistent code formatting.
- Avoid unnecessary code duplication.

## Testing

Google PageSpeed Insights was used to test the website in Desktop mode. The recorded scores were 98 for Performance, 92 for Accessibility, 100 for Best Practices, and 100 for SEO.

Further testing can be performed using Lighthouse, WAVE, or axe to identify specific accessibility issues and verify improvements.

## Learning Outcomes

This task helps develop an understanding of website performance measurement, semantic HTML, accessibility principles, CSS optimization, and web quality testing. It also highlights the importance of making websites usable for people with different abilities.

## Conclusion

The ShopEase website achieved strong results in the desktop PageSpeed Insights audit, including a Performance score of 98 and an Accessibility score of 92. The project demonstrates the importance of evaluating website quality and identifying opportunities for further improvement. Additional accessibility checks and optimization can help make the website more efficient and inclusive.
